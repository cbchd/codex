# Person Notes App

This is a simple React Native app using React Native Paper.

## Features
- Maintain a list of people
- Add notes for each person
- Search for people by name

## Requirements
- Node.js (latest)
- React Native CLI

## Run
Install dependencies:
```bash
npm install
```

Start the Metro bundler:
```bash
npm start
```

Run on device or emulator (requires `@react-native-community/cli` which is
already listed in `devDependencies`):
```bash
npx react-native run-android  # or run-ios
```

## Test
To run unit tests:
```bash
npm test
```
